# Only Angels: Собрать смену

Браузерный платформер на Phaser 3.90 + TypeScript. 6 глав, 12 уровней, четыре участника команды, два босса, оригинальная программно нарисованная графика и синтезированная музыка. Фотографии не включены в сборку: они использованы только как референсы внешности и бренда.

## Запуск

Требуется Node.js 20.19+ или 22+.

**Самый быстрый запуск готовой сборки:** распакуйте архив, запустите `Start-Game.cmd` на Windows или выполните `node serve.mjs`. Откройте http://localhost:4173. Установка зависимостей для этого способа не нужна. Окно сервера нужно оставить открытым.

Для разработки из исходников:

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173). На телефоне в той же Wi-Fi-сети откройте адрес `Network`, показанный Vite; локальный сетевой доступ должен быть разрешён системой. Удобнее горизонтальная ориентация.

```sh
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Его можно разместить на любом статическом HTTP/HTTPS-хостинге. Не открывайте `index.html` через `file://`: модульные скрипты требуют веб-сервер.

## Управление

| Действие | Кнопка |
|---|---|
| Движение | A/D или ←/→ |
| Прыжок, высота зависит от удержания | Пробел |
| Рывок | Shift |
| Взаимодействие с заданием или выходом | E |
| Ударная волна «Штраф» | F |
| Пауза | Esc |

На узких и сенсорных экранах доступны крупные экранные кнопки с поддержкой нескольких одновременных касаний. Значок E над объектом обозначает доступное взаимодействие. Настройки громкости доступны из меню и паузы. Музыка включается только после действия пользователя.

## Прогресс

- Светящиеся флажки сохраняют безопасную точку возрождения и восстанавливают здоровье.
- Продолжение возвращает к последней контрольной точке. При потере здоровья или падении число попыток не ограничено.
- Прогресс хранится в `localStorage` под ключом `only-angels-v1`. Он относится к браузеру и адресу сайта, не синхронизируется между устройствами. Прогресс локального запуска и опубликованного сайта раздельный.
- Обязательные задания отмечены стрелками. Если объект остался позади, указатель направит к нему. Возвращаться по платформам можно в обе стороны.
- Секреты дают дополнительный тотал. Повторный подбор одной награды не увеличивает общий тотал повторно. Финал не требует гринда.
- Командные точки ✦ включают способности найденных коллег. Артём дополнительно подсвечивает секреты. Кофе даёт ускорение и здоровье.
- Боссов можно бить прыжком сверху и «Штрафом». Стрельба принтера предваряется надписью «ПЕЧАТЬ!».

## Исходники

- `src/main.ts` — Phaser-сцена, собственная платформерная физика, управление, меню, сохранения, боссы и финал.
- `src/art.ts` — оригинальная векторная графика, анимация героя и персонажей, многослойные фоны.
- `src/data.ts` — диалоги, 12 карт, параметры тотала, противники, способности, схема сохранения.
- `src/style.css` — адаптивный интерфейс.
- `tests/verify.cjs` — воспроизводимая симуляция настоящего игрового кода без графического вывода.
- `QA-results.json` — результаты последнего автоматического прогона.

Карты детерминированы и состоят из повторяемых секций с вариациями высот, верхними маршрутами и тематическими объектами. Число секций, расположение заданий, награды и способности меняются в `src/data.ts`. Голосовые файлы не предоставлены; все реплики доступны текстом. Для интерфейса используются Manrope и Marck Script из Google Fonts с системными запасными шрифтами; сама игра не требует внешних графических ресурсов.

## Проверки и длительность

```sh
node tests/verify.cjs
npm run build
```

Проверены маршруты всех 12 уровней с подбором обязательных предметов, оба боя с боссами через обычные прыжки и «Штраф», coyote time, буфер прыжка, перезарядка, возрождение, сохранение контрольной точки, повреждённое сохранение, открытие уровней, набор команды и финал без обязательного сбора секретов.

Автоматический маршрут при 60 шагах симуляции в секунду занял **3719,1 игровой секунды (61 мин 59 с)**, отдельные бои — **13,7 и 17,5 секунды**. Это ускоренная симуляция, а не час ручной игры: у бота известна геометрия, он выбирает прыжок у края и может многократно ошибаться. Диалоги и изучение управления в этот замер не входят. Результат показывает достижимость и даёт ориентир для настройки, но **не подтверждает 50–70 минут первого прохождения человеком**.

В настольном Chromium проверены запуск, интерфейс, пауза, сенсорные кнопки при размере 844×390 и отсутствие ошибок JavaScript. Полный ручной плейтест кампании, Safari/iOS и физическое Android-устройство не проверены. Перед широким командным релизом нужны реальные плейтесты длительности и удобства управления.

Проект Sites создан как приватный, но публикация не завершена: соединение с хранилищем исходников `git.chatgpt-team.site` завершилось тайм-аутом и ошибкой TLS handshake. Рабочие исходники и собранный сайт сохранены локально. Публичный доступ отдельно не включался.
